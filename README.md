# React Todo App

A simple and responsive Todo List application built using React.js and Vite.  
Users can add, delete, and manage daily tasks with a clean and fast UI.

## Features
- Add new tasks
- Delete tasks
- Mark tasks as completed
- Responsive design
- Fast development with Vite

## Tech Stack
- React.js
- Vite
- JavaScript
- CSS

## Installation

```bash
npm install
npm run dev
